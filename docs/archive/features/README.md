# 已归档功能评审文档

这些是功能开发过程中的 friction review、closure review 和 spike review。
它们记录已完成功能的实现闭环和问题发现，不再代表当前需要处理的事项。

## 类别说明

| 类别 | 文件数 | 说明 |
|------|--------|------|
| Closure review | 8 | 各功能 first slice 收口记录 |
| Friction review | 8 | 开发过程中暴露的问题记录，已解决 |
| Spike review | 4 | Short spike 后的设计验证结论 |
| Handoff checkpoint | 1 | Agent loop branch handoff 记录 |
| Spike selection | 1 | Worker handoff app spike 选择 |

当前活跃功能入口以 `docs/current/` 和 `docs/features/` 保留的文档为准。
