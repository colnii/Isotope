## 4. What This Demo Proves

Current v0.2 developer demo proves:

- canonical event log remains the source of truth.
- event replay can rebuild projected state.
- checkpoint-assisted rebuild can recover an equivalent read model.
- in-process `HttpApiApp` facade can drive session / run / input / state / events / artifact summary paths.
- approval pause / resume boundary works: pending approval can be approved, then resumes through the existing executor path.
- controlled artifact content policy works at retrieval layer with structured `ResourceRef`, explicit grants, caller context, and purpose.
- memory remains `boundary_only`; memory read-model / checkpoint boundaries exist, but durable memory storage/query is not implemented.

## 5. What This Demo Does Not Prove

Current v0.2 developer demo does not prove:

- real HTTP server or network listener.
- real LLM integration.
- durable memory storage.
- real memory query engine.
- external ingestion / `ImportedSnapshot`.
- production auth / identity.
- approval UI / notification / timeout scheduler.
- hosted deployment or production release packaging.
- public HTTP full-content artifact route.
