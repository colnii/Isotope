# v0.1 Demo Acceptance

状态：`accepted as developer demo`

## 1. What This Demo Is

这是 Isotope kernel 的 v0.1 developer demo，用来展示当前最小内核闭环，而不是产品级 runtime。

demo 的验收目标是证明一个本地 deterministic path 可以跑通：

```text
session -> run -> action compiler -> policy -> executor -> artifact -> canonical events -> projector -> checkpoint -> replay verification
```

它不承诺 real LLM、HTTP server、UI、durable memory storage、external ingestion 或 plugin system 已可用。
