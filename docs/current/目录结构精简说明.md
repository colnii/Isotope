状态：当前目录快照。更新时间：2026-05-23。

本文是精简版目录树，只记录 `docs/` 和 `tests/` 以外的 Git tracked 文件。
行尾 `#` 注释刻意保持短句，适合快速浏览代码和入口结构。

## 生成范围

- 文件数量：170 个 tracked 非 docs/tests 文件。
- 目录数量：43 个非 docs/tests 目录，包含根目录。
- 已排除：`docs/`、`tests/`、`.git/`、`.venv/`、`.worktrees/`、`.pytest_cache/`、`__pycache__/`、`*.egg-info/`、本地私有配置。
- 精确清单命令：`git -c core.quotePath=false ls-files | rg -v '^(docs|tests)/'`。

- `apps/`：命令和 API 薄入口。
- `src/isotope/`：真实产品代码。
- 根目录文件：项目说明、协作规则和 Python 配置。
