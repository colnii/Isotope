# v0.2 Demo Scenario

状态：`implemented`

## 1. Purpose

本文定义并记录一个最小 v0.2 developer demo scenario，用来让当前 closed 的 Track A / C / E 在 demo 中可见。

目标不是把 Isotope 变成产品 CLI，也不是打开 real HTTP server、real LLM、durable memory storage/query 或 external ingestion。目标是保持 deterministic / in-process / no-network 的前提下，扩展现有 demo 的展示范围。

当前实现状态：

- baseline：`735 passed`。
- `python -m isotope_kernel.demo --scenario v0.2` 可输出短 plain text summary。
- `python -m isotope_kernel.demo --scenario v0.2 --json` 可输出 parseable JSON summary。
- default `python -m isotope_kernel.demo` / `--json` 仍保持 v0.1 行为兼容。

## 2. Scenario Constraints

v0.2 scenario 必须保持：

- deterministic，无 real LLM。
- in-process，无 real HTTP server / network listener。
- 不引入 FastAPI / Flask / new dependency。
- 不实现 durable memory storage / query。
- 不打开 HTTP full-content route。
- 不输出 artifact full content，除非在 JSON 中只用 boolean / policy summary 证明 authorized retrieval boundary。
- 不污染 repo 根目录，继续使用 temp storage。
- 默认 v0.1 demo 行为保持兼容。

## 3. What The Scenario Should Show

### Track A: HTTP API Facade

通过 `HttpApiApp` / `create_http_app(...)` 跑一条 in-process request path：

- create session。
- create run。
- submit input。
- read run state。
- read events。
- read artifact summary。

输出只需要说明 `http_api_ok: true`，不需要展示完整 HTTP response。

### Track C: Artifact Content Policy

展示 artifact summary 默认可读，并证明 full-content retrieval 仍受控：

- summary retrieval 返回 summary / ref / provenance，不返回 full content。
- controlled full-content retrieval 只有 structured `ResourceRef` + explicit grants + caller context / purpose 时成功。
- unauthorized retrieval fail closed 或 downgrade，不读取 content。
- HTTP full-content route 继续 `501 not_enabled`。

输出只需要说明 `artifact_content_policy_ok: true`，不要把 full content 打印到 plain text 或 JSON。

### Track E: Approval Pause / Resume

展示一个需要 approval 的 action：

- request action 进入 `pending_user_approval`。
- `approval.requested` 出现在 canonical events。
- approved resolution append `approval.resolved`。
- approved path 通过现有 executor boundary resume 并完成。
- denied path 可作为 JSON summary 中的 secondary check，或只在 tests 中覆盖。

输出只需要说明 `approval_ok: true`，并可包含 pending / approved / denied 的 summary counts。

## 4. Proposed Command

保持现有默认 demo 不变：

```bash
python -m isotope_kernel.demo
python -m isotope_kernel.demo --json
```

新增 explicit scenario：

```bash
python -m isotope_kernel.demo --scenario v0.2
python -m isotope_kernel.demo --scenario v0.2 --json
```

`--scenario v0.2` 是 developer demo scenario，不是长期 CLI contract。

## 5. Proposed Output

Plain text 至少包含：

- `scenario: v0.2`
- `run_status`
- `http_api_ok`
- `approval_ok`
- `artifact_content_policy_ok`
- `checkpoint_ok`
- `memory_status: boundary_only`

JSON 至少包含：

- `scenario`
- `session_id`
- `run_id`
- `run_status`
- `http_api_ok`
- `approval_ok`
- `artifact_content_policy_ok`
- `checkpoint_ok`
- `memory_status`

JSON 不应包含：

- `content`
- `full_content`
- `artifact_content`
- `raw_content`
- `raw_artifact_content`

## 6. Non-Goals

- real HTTP server。
- network listener。
- FastAPI / Flask / dependency selection。
- real LLM。
- memory storage / query。
- external ingestion。
- approval UI / auth / notification / scheduler。
- public full-content HTTP route。
- binary streaming / pagination。
- product CLI polish。
